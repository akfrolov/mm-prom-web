# REGRESSION — сквозной smoke-сценарий сайта

> Полный проход по текущему сайту без правок: все страницы по `file://`,
> навигация, консоль, анимации, карты. Заполнять по строке на спринт.
> Запуск — Playwright по `file://` (`skill('webapp-testing')`); сеть нужна
> только внешним ресурсам: Google Fonts (Inter, Material Symbols), фото
> `invest-platforma.com` / `mm-prom.ru`, Яндекс.Картам.

## Ожидаемое поведение среды

- Ошибки/задержки внешних ресурсов (шрифты, фото, карты при отсутствии
  сети) — ожидаемое поведение `file://`, не дефект. Обнулять их нужно
  отдельными пометками, не маскируя остальные ошибки консоли.
- Ожидание рендера: `document.fonts.ready` перед скриншотами (догрузка
  внешних шрифтов меняет метрики).
- Анимации: при контексте `reducedMotion: 'reduce'` ничего не движется
  (`assets/site-anim.js` обязан уважать настройку).

## Сценарий

1. Открыть каждую страницу из таблицы выше по `file://` (все 22).
2. На каждой: консоль без ошибок, кроме ожидаемых внешних сетевых.
3. Навигация: шапка → «Услуги» (мега-меню, три роли) → переходы на все
   страницы услуг; подвал → «О компании», «Публикации», «Контакты»;
   каталог → карточки ведут на существующие `*.html` (битых ссылок нет).
4. Мега-меню: наведение/клик по каждой роли открывает свой блок, ссылки
   кликабельны; без «мёртвых» кнопок.
5. Страницы с картой (17): карта инициализируется (контейнер карты
   отрисован, `ymaps` загрузился), метки объекта на месте: оба брендбука
   (Атлас Гаражный, Аврора Витебский), каталог, 4 роли, 10 услуг.
6. Скриншоты desktop (1280×800) и mobile (390×844) по одной контрольной
   странице каждого типа (index, каталог, услуга, брендбук, контакты);
   раскладка не разваливается, хедер/футер на месте.
7. `prefers-reduced-motion: reduce`: плавающие квадраты и reveal-анимации
   отключены, скролл страницы работает.
8. Сверка шапки/подвала: блоки побайтово одинаковы во всех страницах —
   `python3 tools/sync_partials.py --check` (22/22, 0 ошибок).
