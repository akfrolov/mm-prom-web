## Текущее состояние (снять по коду, 2026-10-23)

### BaseLayout — head

`src/layouts/BaseLayout.astro` (275 строк) — единственное место разметки каркаса.
Props: `title`, `description`, `noindex?`. Окружения: `MMPROM_ENV=staging`
даёт `noindex, follow` и убирает Метрику; prod — `index, follow` + Метрика
№109764749 (inline, noscript-фолбэк). Canonical строится из `Astro.url.pathname`
и `Astro.site`.

Head содержит:

- favicon: `<link rel="icon" type="image/png" href="/mmprom-logo.png">`
  (строка 30; целевая замена на `mm-logo.png` — п. 3, ещё не внесена);
- canonical, OG (`og:type=website`, `og:site_name=ММ Пром`,
  `og:image=/mmprom-logo.png`, `og:locale=ru_RU`);
- шрифты: preconnect `fonts.googleapis.com`/`fonts.gstatic.com` +
  **Inter wght 400–800** и **Material Symbols Outlined**; **Manrope не
  подключён** (п. 7 не внесён);
- `public/assets/site-anim.css?v=1` (подключён в BaseLayout);
- `<slot name="head" />`; Метрика только в prod.

Скрипт `public/assets/site-anim.js?v=1` подключается в хвосте каждой
страницы отдельно (не в BaseLayout).

## План блоков реализации

Ровно два блока. Порядок: **B1 → B2** (B2 правит то, что B1 уже вынес в
`base.css`); B1 не зависит от B2. Целевые значения — только из CR-пунктов и
эталонных мокапов; «цвета текущие» = фирменная палитра `navy/purple/gold`
сохраняется (токены мокапов `--color-primary:#3D0E6A` и пр. при переносе
подменяются на действующие значения проектом).

### B1 — «base.css, шрифты, шапка, favicon, форма №34»

Scope-контур (CR пп. 3, 5, 6, 7, 19, 21 — часть п. 21):

1. **`public/assets/base.css` (NEW, п. 21)** — вынос общих стилей шапки,
   кнопок и меню (заодно подвала и базовых токенов/`.container`) из 22
   страниц; подключение в `BaseLayout` до slot-стилей страниц
   (`<link rel="stylesheet" href="/assets/base.css?v=1">`); удаление дублей
   из 22 страниц. После выноса grep-контроль: в `src/pages/*.astro` не
   должно остаться `site-header__logo{`, `.mega__`, `.mobile-menu`,
   `.btn{`, `.site-footer`. Внешний вид не меняется правками этого шага
   (кроме пп. 5–7 ниже). Стили секций страниц остаются inline.
2. **Шрифты (п. 7)** — в head `BaseLayout` подключается
   `Manrope:wght@400;500;600;700;800` (Google Fonts), Inter 400–800
   остаётся запасным; стек семейства: Manrope → Inter → system. Шкала
   заголовков и начертания — по макету (`docs/mockups/DESIGN.md`,
   `docs/mockups/index.html`); цвета не меняются.
3. **Шапка (п. 5)** — логотип `site-header__logo img` `height:40px`;
   отрицательные `margin-left` убираются: левая кромка логотипа совпадает
   с левой границей контента секции «Комплексное сопровождение
   промышленного проекта» на главной (обе стороны используют `.container`).
4. **Шапка (п. 6)** — CTA «Оставить заявку»: `min-height:44px`,
   `padding:12px 20px`.
5. **Favicon (п. 3)** — `<link rel="icon" href="/mm-logo.png">`
   (фирменный знак 116×116; `public/mm-logo.png` уже в репо — коммит
   e8540b6). Файл шапки/подвала (`/mmprom-logo.png`) и `og:image`

Общий порядок для обоих блоков (по AGENTS.md «Отступления», верификация

   ошибок.
