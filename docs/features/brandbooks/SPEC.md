## 1. Роль фичи

Две статические страницы-брендбука — единственные страницы объектов с
персональными маршрутами вне будущего семейства `/obekt/<id>/`: карточки
коллекции ссылаются на их внутренние `link` (`/atlas-garazhnyj/`,
`/avrora-vitebskij/`), а не на `/obekt/<id>/` (п. 8 CR). Карта объектов этих
страниц — собственная (не `svc-map`), в критерии CR «карта на 9 страницах…
офисные карты брендбуков не считаются» они не участвовали и теперь не участвуют.

Сейчас обе страницы — сокращённые версии (6 и 3 секции), эталон полной версии
лежит рядом как скачанный HTML (2 файла `.kilo/scripts/sources/...`); задача
B1/B2 — довести разметку/стили/скрипты страниц до эталонного состава,
сделав битые якоря валидными и использовав локальные медиа
(уже в `public/assets/external/`).

## 2. Текущее состояние — общий слой двух страниц

- Head: `title` = «<Название> — ММ Пром»; `description` — **общий текст
  компании** («ММ Пром — единое окно промышленника… 200 000+ м²…»), не
  объектный; canonical/env/OG — из `BaseLayout` (фича site-shell).
- Inline-CSS (строки 5–623, идентичен в обеих страницах, diff пуст): полный
  «общекаркасный» набор 23 страниц сайта (токены, reset, кнопки, шапка,
  мегаменю, мобильное меню, герой, бегущая строка, ленты `.obj-card`,
  стандарты, панельный FAQ, контакты, форма, подвал, particles, reveal) — см.
  `site-pages` SPEC §1. Специфичные для брендбуков добавки:
  - `.obj-deals`/`.obj-deal*` (декор карточек форм сделки, строки 614–620) — живые;
  - `.obj-lead__list` (список в лид-панели атласа, строка 621) — живой;
  - `.brand-squares` (строки 77–78) — **мёртвый** (разметки нет);
  - классы разметки бренда без CSS-правил: `.obj-hero`, `.obj-hero__lead/_facts/
    _fact/_num`, `.obj-specs`, `.obj-spec`, `.obj-spec__icon` — секции героя
    и характеристик рендерятся **неоформленными** (потоки текста и таблицы
    без стилей), т.к. объектные компоненты эталона в страницы не перенесены;
  - `.b-faq__panel/_intro/_help*` — мёртвые (панельный FAQ не используется);
  - `.sq-float*` — мёртвый CSS (разметки нет; глобальная чистка `sq-float--3`
    — фича `site-pages`, imp-pages).
- Tail (идентичен в обеих, diff пуст; атлас 727–884, аврора 670–828):
  1. Яндекс.Карты API 2.1 `id="mmprom-yamap-api-js"`, ключ **`5971e07b-34fb-45e3-9d72-1be19c9ef821`**
     (второй ключ проекта, «брендбук-ключ» по REGRESSION.md), `lang=ru_RU`,
     подключение без ленивости.
  2. Один IIFE ~154 строки — копия каркасного скрипта страниц: `js`-класс;
     счётчики `[data-count]` (на этих страницах разметки нет — мёртво);
     reveal `.reveal` (разметки нет — мёртво); звук видео `.b-hero__video/
     __sound` (нет — мёртво); конвейер `.b-conveyor` (нет — мёртво);
     мегаменю `.mega__role` и мобильное меню (разметка в `BaseLayout` —
     **живые**, дублируют каркасную механику); **офисная карта
     `#office-map`** c guard-проверкой — DOM `#office-map` не существует →
     мёртвый блок (паритет с исходником, REGRESSION.md п. 6).
  3. `site-anim.js?v=1` — defer.
- Связка с коллекцией: `atlas-garazhny.json` / `avrora-vitebsky.json` несут
  `link` → эти маршруты, `external` → mm-prom.ru (устаревающие), фото —
  внешние URL mm-prom.ru (локализация — фича `objects-data`), `presentation`
  → битая `/gejt-broshury/` (известная, не «чинится»).

### 10.5 Мета и заголовки страниц

| Параметр | Аврора | Атлас |
|----------|--------|-------|
| Title | `Индустриальный парк «Аврора Витебский» — ММ Пром` (48 символов, ≈480 px) | без изменений: `Атлас Гаражный — технопарк в Обухово \| ММ Пром` (49 символов, ≈500 px) |
| H1 | `Индустриальный парк «Аврора Витебский»` (38 символов) | `Технопарк «Атлас Гаражный» в Обухово` (36 символов) |
| Видимые заголовки | 20 (было 34) | 16 (было 38) |

- Карточки-ярлыки секций «Характеристики», «Формы сделки» (Аврора) и
  «Характеристики объекта», «Инженерия и участок», «Формы сделки» (Атлас)
  переведены с `h3` на `div.approach-card__title`; смысловые разделы
  (`h2`) и подзаголовки (площади, разрез, CTA) сохраняют `h3`.
- Дубли контентных анкоров устранены: CTA каталога Авроры различаются,
  телефонные анкоры получили скрытые префиксы (`.visually-hidden`).
  Навигационные дубли мегаменю и мобильного меню приняты.
- `description` обеих страниц не менялась.

**Решение агента — на ревью владельца:** title и H1 Авроры короче
эталонного варианта брендбука (лимит длины title ≈580 px); title Атласа
оставлен текущим, так как уже укладывается в лимит и содержит ключевой
запрос в начале.
