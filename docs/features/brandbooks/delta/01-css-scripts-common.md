## W2 — Объектные скрипты: lazy-карта, makeZoom, лайтбокс

**Тип:** ДОБАВИТЬ. **Источник пункта:** п. 26 CR; объектный `<script>`-блок
ЭА 1682–1822 (карта + zoom) и ЭВ 1607–1747 (то же); §5.4 спеки. Каркасные
скрипты эталона (ЭА 1605–1680, ЭВ 1530–1605) НЕ переносятся — каркас
страниц не переписывается (см. п. 4). Управляющая последовательность карт:
ЭА 1681–1724 (API-тег на 1681 — общий ключ `2ae53810-…`, init
`ymaps.ready` 1684–1724, IO rootMargin 250 на 1720–1723); zoom-скрипт
ЭА 1727–1821 (`makeZoom` 1728–1785, обвязка `[data-mp]` 1787–1796,
лайтбокс 1798–1819); для Б b-flow2: ЭВ 1549–1563 — фрагмент внутри
каркасного скрипта ЭВ, переносится в каркасный IIFE Б (п. 3).

**Было → Стало (обе страницы).** Было: в tail единственный скрипт —
каркасный IIFE + статический API-тег Яндекс.Карты 2.1 с брендбук-ключом для
мёртвой офисной карты; объектной карты, зума и лайтбокса нет. Стало:
1. Скрипт инициализации объектной карты переносится из эталона
   (ЭА 1684–1724 → А; ЭВ 1609–1649 → Б); init лениво через

   `ymaps.templateLayoutFactory` + `iconShape` Rectangle; `setBounds`
   (checkZoomRange, zoomMargin 60); клик по метке не перехватывается.
2. Zoom-скрипт мастера-плана переносится целиком (внутри общего блока:
   ЭА 1727–1821; ЭВ 1652–1746): `makeZoom` (колесо пассивно с
   preventDefault, drag при zoom > 1, touch-drag, clamp), инлайн-инстанс
   1–6×, лайтбокс 0,5–8×, открытие/закрытие лайтбокса (кнопка, оверлей,
   Esc), блокировка скролла body.

   каркасный IIFE Б после reveal-блока (как в ЭВ); полоса заполняется

4. Каркасный IIFE страниц не переписывается: его reveal-фрагмент остаётся —
   перенесённая разметка `.reveal` оживляет его; мёртвые ветки (счётчики,
   конвейер, звук) не удаляются вне W3.
5. Скрипты переносятся байт-в-байт одним общим `<script is:inline>`-блоком
   (в эталоне это одна пара тегов `<script>…</script>` с двумя IIFE
   подряд: карта, затем zoom); блок добавляется в tail-слот ПОСЛЕ
   каркасного IIFE (перед `site-anim.js`); API-тег остаётся на своей
   позиции выше по tail (замена ключа — W3).

**Якорь эталона:** ЭА 1682–1822, ЭВ 1607–1747 (каркасные скрипты
ЭА 1605–1680 / ЭВ 1530–1605 не входят в перенос).
