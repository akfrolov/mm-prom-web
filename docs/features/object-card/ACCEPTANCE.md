      типу с фирменными цветами; подпись под фото Колтушей/Волосово/Терволово
      отсутствует.
- [ ] `/arenda/`, `/prodazha/`: карточки ведут на `/obekt/<id>/`; у брендбуков —
      внутренние маршруты; чипы по типу.
- [ ] `/katalog/`: карточки открываются по клику на «Подробнее» (переход по
      ссылке, не модалка); фильтры каталога работают (data-атрибуты на
      карточках сохранены); кнопка карты и поведение карты — фича `catalog`
      (здесь только проверить, что в карточке нет `data-open`).
- [ ] Консоль браузера без ошибок на всех четырёх страницах.

## 6. Решения агента (принять/скорректировать на ревью)

- Имена классов чипов — значения enum `badge--park` / `badge--production` /
  `badge--warehouse` / `badge--land`.
- Текст чипа — `typeLabel` повсеместно: antares станет «Индустриальный
  парк» (вместо «Технопарк»), parnas/volhonskoe/voyskovitsy-park —
  «Производственный комплекс» (вместо «Производственные площади»).
- Каталожный оверлей-чип — фирменный цвет типа (сейчас белый `badge--type`),
  blur-эффект сохранён.
- Формулировка каталожной ссылки-foot: «Подробнее» (не-брендбуки),
  «На страницу объекта» (брендбуки, внутренний маршрут).
