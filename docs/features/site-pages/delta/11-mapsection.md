# Часть 11 — W2.8: компонент `MapSection.astro` (CR п. 21)

Источник правки: CR-2026-002 п. 21; SPEC §1.10, §2.2 («данные передаются
с каждой страницы… удаление секции с 5 страниц — фича services»).

## Было → Стало

| Было | Стало |
|------|-------|
| На 14 страницах копипаст секции: `<section id="map" class="b-map-sec section">` → `sec-index` (номер варьируется по страницам), rowhead (`h2` «Объекты на карте» + `.b-more` «Весь каталог» → `/katalog/`), лид — постоянный текст «27 объектов в Санкт-Петербурге и Ленинградской области: …» (жёсткий, одинаков на всех 14), `.b-map-sec__wrap` → канвас `<div id="svc-map" class="b-map-sec__canvas" role="application" aria-label="Карта объектов ММ Пром">` + `.b-map-sec__bar` (подсказка + `btn--outline` «Смотреть каталог» → `/katalog/`) (эталон development.astro:1039–1055) | `<MapSection objects={mapObjects} />` — секция, rowhead, лид, канвас, подсказка внутри компонента; разметка `id="map"`/`id="svc-map"` в исходниках страниц не встречается |
| Frontmatter страницы собирает `mapObjects` из коллекции, пробрасывает через `<script is:inline define:vars>` → `window.MMPROM_MAP_OBJECTS` | Сбор на страницах остаётся (передаётся пропом), `define:vars`-скрипт рендерится компонентом; имя переменной и состав данных не меняются |
| Хвост страницы: подключение Yandex Maps API 2.1 (apikey… `lang=ru_RU`) + `/assets/svc-map.js?v=1` (defer) | остаётся на страницах (§1.12: хвостовые скрипты — вне фичи; попап карты — зона `catalog`) |

Пропы: `objects` (массив объектов коллекции для карты), `secIndex` (номер
`sec-index` — варьируется по страницам: «07» development, «04» investoram,
«06» sobstvennikam-zdaniy — передаётся страницей), опционально `heading`,
`link` (адрес «Весь каталог», по умолчанию `/katalog/`). Ключи карт и
подключение api/svc-map.js не меняются (инвариант про карты в «Контексте»).

Требование §1.10: «компонент должен поддерживать удаление блока со страницы
без правки других» — вызов `<MapSection>` самодостаточен; страницы atlas,
avrora, blog, 404 (без секции) рендерятся без него (TC-SP-25).

Не меняется: 14 точек вставки (до `imp-services` = 9), лид — постоянный текст
«27 объектов в Санкт-Петербурге и Ленинградской области: индустриальные парки,
производственно-складские комплексы и земельные участки.» (жёстко в разметке
как сейчас — на всех 14 страницах одинаков, не вычисляется из данных),
подсказка-текст, кнопка. Вид и поведение карты —
зоны `catalog`/`services`, не меняются.
