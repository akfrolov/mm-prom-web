обеспечивает заменяемую кнопку» — п. 18/№36, вне этой фичи).

## Было → Стало

| Было | Стало |
|------|-------|

| index (1 из 4): обёртка `reveal tz-panel` (градиент, белый текст, декоративный `::after`), кнопка → `/gejt-tz/` | обёртка `<div class="reveal tz-panel">` остаётся в index.astro; внутри — компонент |
| atlas-garazhnyj экз. 1 (`:656–666`) и avrora-vitebskij (`:656–666`): «Заинтересовал объект?»/«Заинтересовал парк?», «Оставить заявку» → `#contacts`; обёртки `tz-panel` без reveal (atlas-garazhnyj.astro:658+) | то же — через компонент, `ctaHref="#contacts"` |

Пропы: `heading`, `text` (опц.), `ctaHref`/`ctaText` (опц. — при наличии
рендерится кнопка), слот тела (опционально — произвольное содержимое
текстовой колонки, экз. 2 atlas). Кнопка рендерится `SiteButton`
(variant gold + целевой класс `b-tz-banner__cta` — W2.2). Ссылки не меняются:
`/gejt-tz/` на index (замена формой Bitrix24 №36 — п. 18, вне этой фичи;
компонент именно обеспечивает заменяемую кнопку), `#contacts` на брендбук-страницах
(atlas/avrora).
Вид панели: CSS `.b-tz-banner` (сетка, gap) — в blocks.css (W2.1); CSS
панелей `.tz-panel` остаётся в страницах (index, atlas, avrora — W2.1 его не
трогает).
