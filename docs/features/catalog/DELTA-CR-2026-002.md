## Цель изменения

Каталог перестаёт показывать всплывающее окно объекта: карточка, метка карты,
кнопка «Показать на карте» и попапы ведут теперь на страницы объектов
`/obekt/<id>/` и брендбуки — сайт получает понятную навигацию и SEO-страницы
вместо модалок. Числа каталога (итоги, счётчики чипов, счётчик выдачи)
пересчитываются из коллекции, чтобы шесть новых объектов появились без правки
страницы.

## Контекст для исполнителя

Суть: удаляется модальный путь каталога (`#obj-modal` + `openModal`/`closeModal`),
а его три входа и попапы карт направляются на страницы объекта; зашитые числа
заменяются вычислением на билде из коллекции. `svc-map.js` общий для 14 страниц
услуг/ролей — правится только содержимое попапа.

Что НЕ трогать из работающего MVP:

- вид «Список/Карта» (`#view-list`/`#view-map`, `setView`, `initMap`), фильтры
  (сделка/тип/площадь/локация), поиск, сортировка, сброс, empty-state,
  активные чипы — работают как сейчас (гейты SPEC §8);
- конфиг карты: кластеры `gridSize:64`, SVG-иконки 46/56 px, пороги `[10,100]`,
  центр `[59.85, 30.35]`, zoom 9, `suppressMapOpenBlock`, контролы
  (каталог: zoom/fullscreen/geolocation; svc: без geolocation), ленивый старт
  `svc-map` через IntersectionObserver, `setBounds` после отрисовки;
- ключи Яндекс.Карт `2ae53810-…` и `5971e07b-…`, SVG-пин и кластер — CR:
  «скрипты и ключи карт не меняются»;
- DOM-контракт карточек (`data-id/type/deal/area/loc/title`) — интерфейс
  `catalog.js`; рендер карточек — фича `object-card` (план: `imp-catalog`
  идёт после `imp-object-card`);
- инжект `window.MMPROM_OBJECTS` сохраняется; состав полей можно сузить до
  полей карты + URL (SPEC §10.4), переименование переменной `modalObjects`
  допустимо — гейт смотрит `obj-modal` в `katalog.astro`;
- CTA каталога «Оставить заявку» → `/modalka-zayavki/` и телефон
  `tel:88003331010` — известная битая ссылка-заглушка, не «чинить» (план форм
  заявок отдельный);
- секции карт на страницах услуг/ролей (разметка страниц, инжекты
  `MMPROM_MAP_OBJECTS`, бар и подсказки, кнопка «Смотреть каталог») и сужение
  14 → 9 страниц (п. 30) — фича `services`; здесь меняется только `svc-map.js`;
- дизайн каталога по мокапу `docs/mockups/katalog_obektov.html` (расхождения
  §6 SPEC) — CR их не вносит, не делать.

**Источник:** CR-2026-002 п. 8, раздел «Страницы объектов» («карточка в каталоге
