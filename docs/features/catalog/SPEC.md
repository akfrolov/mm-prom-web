## 1. Роль фичи

Каталог `/katalog/` — единственная страница с фильтрами по объектам; выдача
рендерится на билде (27 карточек ObjectCard), скрипт `catalog.js` работает по
data-атрибутам DOM. Вид «Карта» — встроенный переключатель на той же странице.
`svc-map.js` — общий скрипт карты объектов, инжектируемой на 14 страницах
(10 услуг + 4 роли; см. §4). Страницы объектов как отдельных маршрутов нет:
карточки каталога открывают модалку `#obj-modal`, попап карты ведёт в каталог.

CR-2026-002 меняет в этой фиче только переходы: модалка удаляется, все входы
и попапы карт ведут на страницы объектов `/obekt/<id>/` (маршруты — фича
`object-pages`). Данные (+6 объектов) приходят из фичи `objects-data`.

## 3. Текущее состояние — `public/assets/catalog.js`

### 3.1 Данные и фильтрация

- `OBJECTS = window.MMPROM_OBJECTS` → индекс `byId`; состояние
  `state = {deal, type, area, loc, q, sort, view}` (строка 18).
- Границы площади `areaMatch`: s `<2000`; m `[2000; 10000)`; l
  `[10000; 20000)`; xl `≥20000`; пустая `areaNum` проходит только `all`.
- `visible()` — по data-атрибутам карточек: `data-deal` (dealTypes через
  пробел), `data-type`, `data-area`, `data-loc`, поиск `q` — по
  `dataset.title` + текст `.obj-card__addr` (нижний регистр).

### 3.2 Сортировка и рендер

- `sortCards`: default — исходный порядок (data.sort); area-desc/asc —
  объекты без площади в конец; name — `localeCompare('ru')`.
- `apply()`: скрыть все карточки → видимые переставить в сетку
  (`appendChild`), счётчик, empty-state, чипы активных фильтров; при
  `view='map'` — `updateMap(list)`.

### 3.3 Модалка `#obj-modal` (главный объект правок B1)

- DOM (katalog.astro, строки 927–948): `<dialog class="obj-modal"
  aria-labelledby="obj-modal-title">`; заголовок `#obj-modal-title`,
  бейджи `#obj-modal-badges`, адрес `#obj-modal-addr`, крестик
  `#obj-modal-close`, медиа `#obj-modal-media`, описание `#obj-modal-desc`,
  характеристики `dl#obj-modal-specs`, цена `#obj-modal-price` +
  `#obj-modal-price-val`, действия: «Запросить условия» → `/modalka-zayavki/`
  (битая) и «Позвонить» `tel:…`.
- `openModal(id)` (строки 103–122): по `byId`; бейджи — тип + сделки
  (метка «Аренда» → `badge--deal-rent`, иначе `badge--deal-sale`) + busy
  «Нет свободных площадей»; медиа — `o.image` с `onerror→is-broken` и
  заглушкой «Фото: <название>» (`.obj-card__ph`); характеристики — колонки
  `[иконка, подпись, значение]`; цена показывается при непустом (сейчас
  ×3: avrora-vitebsky, atlas-garazhny, varshavskaya); открытие —
  `modal.showModal()` (фолбэк `setAttribute('open')`) + `body` overflow
  hidden.
- Закрытие (строки 123–133): крестик, клик по подложке (`e.target ===
  modal`), событие `close` сбрасывает overflow; Esc — нативное поведение
  `<dialog>`.
- Вход: делегированный клик `[data-open]` (строки 127–130) —
  `preventDefault` + `openModal`; кнопка «Подробнее» в карточке
  (`ObjectCard`, каталожная ветка) — единственный «не-картовый» вход.

### 3.4 Виды и карта каталога

- `setView('list'|'map')` (строки 184–195): aria-pressed, `grid.hidden`,
  `mapWrap.hidden`; при включении карты — `initMap()` + `apply()`.
- `initMap()` (строки 204–236): лениво при первом виде «Карта»,
  `ymaps.ready`; `ymaps.Map('cat-map-canvas')`, центр `[59.85, 30.35]`,
  zoom 9, контролы zoom/fullscreen/**geolocation**, `suppressMapOpenBlock`;
  `ObjectManager`: кластеры `gridSize:64`, иконки SVG 46/56 px,
  пороги численности `[10, 100]`; одиночные метки — SVG-пин
  (фиолетовый `#5A3994`, золотой кружок `#EBB81E`), offset −18,−44.
- **Клик по маркеру → `openModal(id)`** (строки 228–231) — открывается
  модалка, а не попап.
- `updateMap(list)` (строки 238–253): если карта не готова — отложить в
  `pending`; features по `byId` (только объекты с `coords`); properties:
  `hintContent`/`balloonContentHeader` = название,
  `balloonContentBody` = адрес + площадь — **ссылки на объект в попапе нет**;
  после обновления — `setBounds` (checkZoomRange, zoomMargin 40).
- `focusOnMap(id)` + делегат `[data-map]` (строки 255–269): переводит каталог
  в вид «Карта», опрашивая готовость карты каждые 200 мс, центрирует метку
  (zoom 14, анимация 300 мс) и **открывает модалку**; кнопка карты в карточке
  (`ObjectCard`, `.obj-card__map`, `data-map=<id>`) — вход «Показать на
  карте».
- Сброс: `#f-reset`, `#empty-reset`, чипы `data-clear` (строки 160–181) —
  state и контролы в дефолт + `apply()`.

## 5. ObjectCard (каталожная ветка, `showMap`) — DOM-интерфейс catalog.js

Рендер — `src/components/ObjectCard.astro` (строки 17–57), стили —
`public/assets/object-card.css` (+ инлайн-бейджи каталога, §2.4). Правки
рендера — во фиче `object-card`; здесь фиксируется контракт, на котором
работает `catalog.js`.

- Карточка: `article.obj-card.obj-card--cat.reveal` (+ `obj-card--busy`),
  data-атрибуты: `data-id` (id записи коллекции), `data-type`, `data-deal`
  (`dealTypes` через пробел), `data-area` (`areaNum ?? 0`), `data-loc`
  (`location`), `data-title` (`searchTitle` ?? `title.toLowerCase()`) —
  5-точечный вход фильтров/поиска/сортировки/карты.
- Кнопка карты: `button.obj-card__map data-map=<id>`, aria-label
  «Показать на карте: <название>».
- Фут: у брендбуков (`external` = `https://mm-prom.ru/atlas-garazhnyj/` /
  `…/avrora-vitebskij/`) — ссылка «На страницу объекта» `target="_blank"`
  (внешняя!); у остальных — кнопка «Подробнее» `data-open=<id>` (вход
  модалки). Битые ссылки-заглушки (`/kartochka-obekta/` ×4 в полях `link`)
  существуют только в ленточной ветке — каталожная ветка их не использует.
- Плашка busy: «Нет вакантных площадей» в карточке; бейдж «Нет площадей»
  на фото; в модалке «Нет свободных площадей» — три разных формулировки,
  не путать при правках.

## 7. Целевые изменения (источник — CR-2026-002; в код не внесены)

   нет — только адрес/площадь) и в `svc-map.js` (сейчас «Смотреть в каталоге»

### B1 — «Модалка → страницы объектов, карта и попапы»

## 10. Решения агента — на ревью владельца

1. **Зашитые числа каталога (B1.5)** — CR п. 25 требует «+6 объектов видны
   и фильтруются», но прямо не упоминает зашитые статы/счётчики
   (27/4/15/3 и 27/4/15/5/3); предложено пересчитывать их по коллекции на
   билде, чтобы правка не рассинхронизировалась при следующем пополнении.
2. **URL попапов `svc-map.js` (B1.4)** — инжект `MMPROM_MAP_OBJECTS` не
   содержит ссылку; предложено поле `url` в инжектах 14 страниц
   (координация с фичей services) с фолбэком `/obekt/<id>/`; альтернатива —
   конкатенация из `id` с хардкодом двух брендбук-исключений в
   `svc-map.js`.
3. **Маркер и кнопка карты для брендбуков** — CR оговаривает их маршруты
   только для карточек (п. 8); предложено то же правило для маркера карты
   и попапов (внутренние маршруты атласа/авроры, не `/obekt/<id>/`).
4. **Состав `window.MMPROM_OBJECTS` после удаления модалки** — инжект
   (строка 1010) несёт 14 полей, из которых карте каталога нужны 5
   (`id, title, coords, address, area`); предложено сузить состав при
   удалении модалки (поля `specs/price/desc/external/busy/…` не нужны
   каталог-скрипту). Переменную `modalObjects` допустимо переименовать
   (gate смотрит `obj-modal` в `katalog.astro`).
