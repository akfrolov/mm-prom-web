## 1. Роль фичи

`src/pages/index.astro` — страница «/»: 1095 строк в одном файле — разметка
секций, inline-стили (~590 строк, `is:inline` в slot `head`) и inline-скрипт
«оживитель» (~130 строк, `is:inline` в slot `tail`). Из внешних ассетов
страница подключает только `public/assets/object-card.css?v=1` (ленты
карточек); шрифты (Inter + Material Symbols) и `site-anim.css` приходят из
`BaseLayout` (фича `site-shell`). Фича покрывает правки CR, специфичные для
главной; общекаркасные и общестилевые правки — в соседних фичах
(§13 «Границы»).

| Этап | h3 | Ссылка сейчас |
|------|----|----------------|
| 01 | Подбор объекта | `/katalog/` |
| 02 | Стратегия проекта | `/consalting/` |
| 03 | **Юридическое и техническое сопровождение** | **`/development/`** («Девелопмент под ключ») — п. 12 ссылку снимает |
| 04 | Финансирование ваших проектов | `/investcomp/` |
| 05 | Проектирование и строительство | `/stroitelstvo/` |
| 06 | Эксплуатация | `/upravlenie/` |

**Анимация конвейера (десктоп ≥1024)** — один скрипт в tail `index.astro`:

1. `duration = 9000`; цикл привязан к `performance.now()` **на момент
   исполнения скрипта (загрузка страницы)** — не к входу блока в вьюпорт;
2. каждый кадр rAF: `p = (прошло % 9000) / 9000`; `x = p * (ширина конвейера
   − 10px)` → `runner.style.left = x + 'px'` (бегунок: точка 10px + кольцо из
   `box-shadow` — «круг-бегунок» п. 4);
3. каждый кадр: этапу ставится `is-passed`, когда **левый край** бегунка
   достиг **центра** этапа (`x >= (rect.left − конвейерRect.left +
   width/2)`); при обратном пробеге цикла класс **снимается**;
4. подсветка пройденного этапа: номер заливается золотым (контур снят),
   иконка — золотая, h3 — фиолетовый (CSS-переходы ~0.2s) — селекторы
   `.b-steps--conveyor .b-steps__item.is-passed …`;
5. мёртвый CSS: `@keyframes b-conveyor-run` объявлен, но ни одному элементу
   `animation` не присвоено (движение — только JS);
6. мобильный вариант (<1024): вертикальная пунктирная линия слева с золотыми
   точками этапов (`::before`); линия/бегунок скрыты (`display:none`),
   `is-passed` не вычисляется.

Примечание-строка `.b-conveyor__note`: иконка Material Symbols `sync_alt`
(уже по п. 11) + «От подбора площадки до ввода в эксплуатацию — весь цикл
на нас».

**Расхождение п. 4 (заявлено владельцем: «сейчас круг проскакивает раньше
анимации этапа»)**: в коде бегунок и подсветка управляются одним rAF-циклом,
поэтому наблюдаемый рассинхрон объясняют: (а) старт цикла от загрузки
страницы — к моменту прокрутки пользователя до блока цикл уже в произвольной
фазе, этапы помечаются/снимаются вне поля зрения; (б) срабатывание по левому
краю бегунка против центра этапа и снятие подсветки при зацикливании.
Механику синхронизации — на реализацию (§14.2); поведение подтвердить
визуально на visual-шаге.

Стили и скрипт конвейера продублированы inline на 22 страницах (копипаста);
вынос общих стилей в `base.css` — фича `site-pages` (п. 21); здесь
описывается поведение главной.
