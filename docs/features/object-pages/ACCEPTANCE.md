Общий порядок проверки: `npm run build` + `npx astro check` зелёные →
grep DOM-якорей из SPEC §10 → открытие страниц по `astro preview` в
Playwright (навык `webapp-testing`; ширины 360 / 768 / 1024 / 1366, контекст
`reducedMotion:'reduce'`, ожидание `document.fonts.ready`) → консоль без
ошибок.

Зависимости проверок: шаг фичи в плане идёт после `objects-data` (поле
`images`, +6 записей, локальные фото → счёт 31) и `object-card` (карточки
ведут на `/obekt/<id>/`); до/параллельно — согласование с `site-pages`
(компонент `Breadcrumbs`), `site-shell` (форма №34 шапки и хвост BaseLayout)
и `articles` (общие OG-пропсы). Изолированно (без смежных фич) маршрутов
будет 25 (27 записей − 2 брендбука) — счётные проверки B1-1/FIN-3
активируют плановые счётные значения после мерджа `objects-data`; grep-якоря
B1-2…B1-9, B2-1…B2-7 и FIN-1…FIN-8 верны и изолированно.
