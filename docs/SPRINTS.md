# Карта спринтов — ММ Пром

| Статус | Значение |
|--------|----------|
| план | запланировано, не начато |
| реализация | в работе |
| приёмка | готово, ждёт проверки владельца |
| принят | принято; изменения согласованного функционала — только через CR |

> Правило обновления: план спринта составляет `/make-sprint-plan`, приёмку
> запускает `/accept-sprint`. Статус меняется на месте; закрытые строки
> не переписываются задним числом.
