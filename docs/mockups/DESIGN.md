# DESIGN.md — дизайн-система макетов ОП-6 «Новый сайт» (ММ Пром)

Канон для HTML-макетов в `Прототипы/`. Воркер `ui-mockup-worker` обязан следовать
этому документу и вставлять `Прототипы/_head.html` дословно. CSS макета —
черновик продакшн-CSS будущих Gutenberg-блоков (ФТ-BLK-1).

Бренд утверждён 2026-08 (комментарий клиента): логотип `assets/mmprom-logo.png`,
акценты **#3D0E6A** (фиолетовый) и **#EBB81E** (жёлтый), база — белый/чёрный,
шрифт **Averta CY** (в макетах — фолбэк Manrope/Inter, т.к. шрифт лицензионный).
UX-документ `../UX_ОП-6_Новый_сайт.md` в части палитры устарел — приоритет у
токенов `_head.html`. Аудитория консервативная: сайт продуманный и удобный,
без «кричащих» сочетаний; жёлтый — дозированный акцент.

**Правило палитры (уточнение клиента 2026-09): фиолетовый — только для
акцентов** (кнопки, ссылки, линии, иконки). Основной фон страниц — белый.
Большие фиолетовые заливки (hero, CTA-полосы) запрещены; вместо них —
светло-фиолетовые подложки `--color-primary-light` с тёмным текстом.
Единственные допустимые тёмные заливки — подвал `--color-primary-dark`
и левая колонка ролей мегаменю (оверлейная панель — исключение).
Линия геометрического выреза hero-изображения на Главной — градиент
`--color-primary` → `--color-accent`.

## 1. Токены

Все токены объявлены в `:root` файла `_head.html` — в макете использовать
только переменные, не сырые hex (кроме редких rgba-поверхностей статус-бейджей).

| Токен | Значение | Назначение |
|---|---|---|
| `--color-primary` | `#3D0E6A` | Фиолетовый — только акценты: primary-кнопки, ссылки, активные состояния, линии |
| `--color-primary-dark` | `#2A0949` | Ховер primary, тёмная поверхность подвала |
| `--color-primary-light` | `#F3EEF9` | Светло-фиолетовая подложка блоков: CTA-баннеры, выделенные секции |
| `--color-primary-soft` | `#E5D9F3` | Светлые линии/бордеры на светло-фиолетовых подложках |
| `--color-accent` | `#EBB81E` | Дозированный жёлтый: бейджи-акценты, маркеры этапов, подчёркивания |
| `--color-bg` | `#FFFFFF` | Основной фон — белый, по умолчанию для всех секций |
| `--color-surface` | `#F7F5FA` | Подложки чередующихся секций |
| `--color-text` | `#161519` | Основной текст (почти чёрный) |
| `--color-text-muted` | `#5C5866` | Вторичный текст, подписи |
| `--color-border` | `#E4E1EA` | Границы, разделители |
| `--color-success` | `#1E8A4C` | Не используются: статусы занятости выведены (2026-09, правки после созвона) |
| `--color-warning` | `#B98900` | Не используются: статусы занятости выведены |
| `--color-neutral` | `#6B6B74` | Нейтральный цвет маркеров/кластеров карты |
| `--font-main` | Averta CY, Manrope, Inter, system | Семейство по умолчанию |
| `--logo-url` | `assets/mmprom-logo.png` | Логотип (относительно любого HTML в `Прототипы/`) |
| `--radius` / `--shadow` / `--container` | 12px / мягкая тень / 1280px | Радиусы, тени, ширина контента |

### Типографика

`clamp()`-шкала из `_head.html`: h1/h2/h3/body/small. Заголовки — вес 800
(Manrope ExtraBold ~ Averta CY Bold), текст — 400–500. Иерархия: ровно один
`<h1>` на страницу; секции — `<h2>`, карточки — `<h3>`.

### Кнопки (CTA-иерархия UX §3)

| Класс | Вид | Когда |
|---|---|---|
| `.btn--primary` | Фиолетовая заливка, белый текст | Главный CTA: «Оставить заявку» (шапка, единый), «Обсудить проект», «Получить презентацию объекта» |
| `.btn--accent` | Жёлтая заливка, тёмный текст | Редкий акцентный CTA (1 на страницу максимум) |
| `.btn--outline` | Контур фиолетовый | Вторичный CTA: «Смотреть все объекты», «Подробнее» |
| `.btn--ghost` | Белая с серым контуром | Третичный: «Все услуги», фильтры |

Touch-target ≥ 44px высотой (заложено в `.btn`); иконки-кнопки — не меньше 44×44.

### Статусы занятости (выведены, 2026-09)

Статусы «Свободно»/«Резерв»/«Занято» из прототипа убраны полностью: ни чипов,
ни `badge--free/reserve/busy`, ни статусных фильтров; маркеры и кластеры карты —
нейтральный `--color-neutral`, aria-label «Объект», легенда — только
«Кластер — число объектов». Бейдж **типа** объекта остаётся. Типы
(«Индустриальный парк / Технопарк / Здание / Помещение / Земельный участок»)
кодируются цветом пастельных подложек: парк — жёлтый (`badge--park`),
технопарк — жёлтая пастельная подложка семейства `--park`
(`badge--technopark`, `rgba(235,184,30,.18)`, тёмный текст), здание —
фиолетовый (`badge--building`), помещение — голубой (`badge--premises`),
участок — зелёный (`badge--land`) — правка 2026-09-30, каталог объектов.
Токены статусов в `_head.html` сохранены (канон), но в разметке не
используются.

### Цены

Цена за площадь пишется «от N ₽/м²» — без «/год» и «в год» (в карточках
каталога, карточке объекта, попапе карты, плейсхолдерах фильтров).

### Изображения

- Если в frontmatter спеки есть поле `изображения` — использовать указанный
  URL/путь в блоке с соответствующим `data-block`.
- Иначе — заглушка: `<div class="img-placeholder" data-img="описание" …>` с
  иконкой `image` (Material Symbols) и подписью, например «Фото объекта».

## 2. Канон шапки и подвала

### Шапка — `<header class="site-header">` (одна на файл)

```html
<header class="site-header">
  <div class="container site-header__inner">
    <a class="site-header__logo" href="index.html"><img src="assets/mmprom-logo.png" alt="ММ Пром"></a>
    <nav class="site-header__nav" aria-label="Основное меню">
      <!-- ≥1024: видна. Пункты: Услуги (href="megamenu.html" + data-megamenu), Каталог, Блог, О компании, Контакты. Иконки поиска НЕТ (глобальный поиск отменён; поиск — только в «Публикациях») -->
    </nav>
    <div class="site-header__actions">
      <a class="site-header__phone" href="tel:88003331010">8 800 333 10 10</a>
      <a class="btn btn--primary site-header__cta" href="#" data-modal-open>Оставить заявку</a>
      <a class="site-header__burger" href="mobilnoe_menu.html" aria-label="Открыть меню">…</a>
    </div>
  </div>
</header>
```

- Логотип-ссылка всегда ведёт на `index.html` (если макет существует; иначе `/`).
- Телефон `8 800 333 10 10` (из спеков; резервный канал Стратегии).
- CTA шапки: `href="#"` + `data-modal-open` → оверлей `modalka_zayavki.html`.
- Пункт «Услуги» — ссылка `href="megamenu.html"` с атрибутом `data-megamenu`
  (подчёркнут точечной линией снизу).
- Бургер `<a class="site-header__burger" href="mobilnoe_menu.html">` —
  ссылка на демо-страницу мобильного меню. В демо-оверлеях открытого меню
  допускается `<button>` (снимок раскрытого состояния).

### Правила текстов (шапка, подвал, CTA)

- Бренд пишется «ММ Пром» — раздельно, оба слова с заглавной; не «ММПром»
  и не «ММ ПРОМ». Латинское имя файла логотипа `mmprom-logo.png` не меняется.
- Вместо «брошюра» — «презентация объекта»: кнопка «Получить презентацию

- CTA шапки — «Оставить заявку», единый на всех страницах.
- В теле страниц CTA варьируем синонимами, чтобы не повторяться (таблица
  ниже). Технические написания при этом не меняются: URL `t.me/…`,
  якорь `id="telegram"`, имена файлов `gejt_broshury.html`, `gejt_tz.html`.
- Слово Telegram в видимых текстах — по-русски «Телеграм».
- «Trade-in» — по-русски «Трейд-ин».
- «Redevelopment» — по-русски «Редевелопмент» (в тексте — «редевелопмент»).
- Услуг — **9** («Строительство» и «Редевелопмент» добавлены; «Срочный выкуп»

- Глобального поиска на сайте нет: иконка/пункт «Поиск» в шапке и меню
  не используются; локальный поиск — только на странице «Публикации»
  (`blog.html`, `action="#"`, inline-фильтр по карточкам).

## 3. Маппинг блоков ФТ-BLK-1 → классы секций

Каждая секция: `<section id="<уникальный-id>" data-block="<блок>" class="b-<тип> …">`.
`data-block` — из спеки страницы (§«Блоки страницы»); тип — по таблице.

| Блок (ФТ-BLK-1) | Класс `.b-*` | Конспект |
|---|---|---|
| Герой | `b-hero` | h1 + подзаголовок + метрики/CTA; фон — белый, текст тёмный. На Главной и «О компании»: изображение с геометрическим вырезом (`clip-path: polygon(...)`), по контуру выреза — акцентная линия (градиент `--color-primary` → `--color-accent`) |
| Преимущества | `b-advantages` | Сетка плиток 4→2→1 с иконками Material Symbols |
| Сетка объектов | `b-objects-grid` | `.grid--4` мини-карточек; бейдж типа объекта; CTA «Подробнее»/«Презентация» |
| Карточка объекта | `b-object-card` | Компактная карточка: фото-заглушка, название, площадь, локация, цена «от N ₽/м²»; статусы занятости не используются. На Главной карточки объектов (секция «Объекты», три рейла) используют анатомию каталога `.obj-card` — единый паттерн с `katalog_obektov.html`: строка бейджей + ↗-ссылка на всю карточку, мини-кнопка «Презентация» поверх медиа, мета-список с иконками; реальные фото парков — через `.b-media` (фото + `figcaption`), остальные — `.img-placeholder` |
| CTA-баннер | `b-cta` | Полоса с заголовком и кнопкой; подложка светло-фиолетовая `--color-primary-light`, текст тёмный, кнопка `.btn--primary` |
| Форма заявки | `b-form` | Простая форма «Обратная связь»: Имя*, Фамилия, Название компании, способ связи — радио-чипы Телефон/Телеграм/MAX/Ватсап/Почта, Телефон*, Email, Комментарий, чекбокс согласия ПД (текст без ссылки или неактивный `<span>`, см. §2), кнопка отправки; скрытые CRM-поля сохраняются |
| FAQ | `b-faq` | Аккордеон `<details>`/`<summary>` — открыт первый вопрос |
| Этапы процесса | `b-steps` | Нумерованные шаги 1–7, на десктопе горизонтально, ниже 1024 — вертикально |
| Кейсы | `b-cases` | Карточки с обложкой-заглушкой, тегами, заголовком |
| Контакты и карта | `b-contacts` | Реквизиты + карта-плейсхолдер (серо-фиолетовая сетка, пин) |

Простая форма «Обратная связь» (см. `b-form`) — во всех формах обратной
связи, гейтах и модалке заявки: форма = просто способ оставить контакты.
Сложная форма «Подбор объекта» — только в релевантных разделах: секция
`id="podbor"` в Каталоге, 17 параметров запроса из чек-листа отдела продаж +
контактный блок простой формы; три шага (CSS-radio, без JS): О задаче →
Требования к объекту → Контакты; сабмит на шаге 3; от 768px — 2 колонки.

Служебные (не из ФТ-BLK-1): `b-filters` (фильтры каталога), `b-breadcrumbs`
(хлебные крошки), `b-article` (тело статьи), `b-gallery` (галерея),
`b-table` (таблица характеристик), `b-plans` (поэтажные планы),
`b-lots` — «Свободные лоты» в карточке объекта: перечень свободных лотов
единого имущественного комплекса (таблица Лот/Тип/Площадь/Мощность/Высота/
Ставка на ≥768; карточки-пары на <768; статусные бейджи занятости не
используются),
`b-tasks` / `.role-card` — компактные карточки-роли на страницах услуг
(иконка, название роли, 3–4 коротких акцента на языке роли,
«Подробнее →» на хаб роли),
`b-others` / `.other-card` — сетка «Другие услуги» на страницах услуг
(8 карточек-ссылок, вся карточка — одна ссылка, декоративная круглая стрелка
`↗` `arrow_outward`, иконка + название + короткое описание; сетка 1→2→3),
`b-projects` / `.proj-card` — сетка «Реализованные проекты» на страницах
услуг (бывш. «Портфолио», 2026-10; некликабельные `<article>`, см. §7),
`b-overlay-*` (оверлеи: `b-overlay-panel`, `b-overlay-modal`, `b-overlay-gate` —
гейты «Гейт брошюры» и «Гейт ТЗ»),
`b-search` (строка поиска + результаты), `b-empty` (пустые состояния).

## 4. Оверлеи (демо-страницы)

Мегаменю, Мобильное меню, Модалка заявки, Гейт брошюры, Гейт ТЗ генерируются как
**демо-страницы**: сверху каноническая шапка (с бургером), затем фон-страница
затемнён/приглушён, поверх — сам оверлей в раскрытом состоянии:

- `<section class="b-overlay-panel">` — Мегаменю: широкая панель под шапкой
  (держатель расширяется до 1440px от 1024px), кнопка закрытия «×» — плавающая
  в правом верхнем углу панели (44×44, круглая, не занимает отдельную полосу),
  раскладка ≥1024 — 2 колонки: слева **вертикальные вкладки ролей** (~280–320px),
  справа группы услуг (3 колонки); колонки разделены вертикальной волосяной
  линией. Левая колонка ролей — тёмная: тёмная подложка
  `--color-primary-dark`, белый текст (оверлейная панель — исключение из
  правила палитры). Над вкладками — микрозаголовок «Решения под вашу задачу»
  (uppercase, `--fs-small`, приглушённо-белый). Вкладки — **плоский плотный
  список** (не карточки): внешних `margin`/`gap` нет, весь воздух — внутренний
  `padding` вкладки (~10–12px по вертикали, 12px по горизонтали), разделитель
  `border-bottom:1px solid rgba(255,255,255,.16)`, у последней на ≥768
  подчёркивания нет (класс-модификатор `mm-tab--last`); активная — подложка
  `rgba(255,255,255,.08)` и акцентная планка 3px слева (`--color-accent`),
  имя — белое. Вкладки — radio-CSS без JS: **вкладки «Все услуги» в левой
  колонке нет**, скрытый radio `#mmf-all` (checked по умолчанию) существует
  только для сброса; видимы 4 роли (только имя — переключатель `label`), под
  именем — краткое описание `--fs-small`
  `rgba(255,255,255,.72)` и **инлайн-ссылка «Подробнее →»** после описания
  (вне `label`, ведёт на хаб роли, иконка `arrow_forward`; в потоке текста,
  отдельной колонки не занимает). Над группами услуг — **чип-заголовок**:
  по умолчанию «Все услуги» без ✕, при выборе роли — «Услуги для <роли>» с ✕
  (сброс к «Всем услугам» через `<label for="mmf-all">`, чистый CSS).
  Фильтрация чистым CSS (не менялась):
  `#mmf-<роль>:checked ~ .mm-groups .mm-item:not([data-roles~="<роль>"]){display:none}`,

## 6. Адаптивность (обязательно)

Классы устройств: **<768 смартфон, 768–1023 планшет, ≥1024 десктоп**.
Контрольные ширины: 360 / 768 / 1024 / 1366. Подход — mobile-first:
базовые стили = смартфон, далее `min-width` media queries.

| Брейкпоинт | Что меняется |
|---|---|
| 360 (база) | Одна колонка; шапка: логотип + бургер (CTA скрыт); все сетки 1 колонка |
| ≥768 (планшет) | Сетки → 2 колонки; шапка всё ещё с бургером; CTA шапки появляется |
| ≥1024 (десктоп) | Полное горизонтальное меню, бургер скрыт; сетки 3–4 колонки; фильтры каталога — левой колонкой |
| 1366 | Контрольная ширина дизайна; контент ограничен `--container` |

### Правила по типам блоков

- **Сетка объектов**: 4 колонки (десктоп) → 2 (планшет) → 1 (смартфон).
- **Таблицы характеристик**: на смартфоне → карточки-пары «параметр — значение»
  (или горизонтальный скролл таблицы).
- **Фильтры каталога**: смартфон/планшет — чипы-скролл горизонтально или
  аккордеон «Фильтры»; десктоп — левая колонка ~320px.
- **Формы**: простая форма «Обратная связь» — одна колонка; сложная «Подбор
  объекта» (Каталог, `id="podbor"`) — от 768px две колонки; поля и кнопки ≥ 44px.
- **Этапы процесса**: смартфон/планшет — вертикально; десктоп — горизонтально.
- **FAQ**: аккордеон на всех ширинах.
- **Оверлеи**: на смартфоне во весь экран; от 768 — центрированная панель/диалог.

### Жёсткие запреты

- Фиксированные ширины > 480px **вне `:root`** запрещены (проценты/flex/grid).
- Touch-target любого интерактива ≥ 44px.
- Горизонтальный скролл на 360px недопустим — мысленный тест каждой страницы.
- Каждая страница содержит ≥ 2 media query (границы 768 и 1024).

### Порядковые индексы секций — `.sec-index`

Декоративная строка над `<h2>`: короткая жёлтая линия (`::before`, 28×3px,
`--color-accent`) + приглушённый номер (`02`, `03`, …, uppercase,
`--color-text-muted`). Герой не нумеруется (там `<h1>`). Элемент —
`<p class="sec-index" aria-hidden="true">`; в секциях с `.b-rowhead`
ставится первым ребёнком (займёт полную строку над заголовком).

### `b-marquee` — бегущая строка метрик

Тонкая полоса сразу после героя (не секция — без `data-block`): фон
`--color-primary-light`, тёмный текст, разделители — жёлтые точки
(`::after`, 8px, `--color-accent`). Трек `width:max-content` из **двух
одинаковых последовательностей** (`b-marquee__seq`, дубликат —
`aria-hidden="true"`), анимация `translateX(-50%)` ~30s linear infinite.
`prefers-reduced-motion: reduce` → анимация выключена, дубликат скрыт,
строка статична (wrap). Контент полосы — те же метрики, что в герое.

### `b-steps--numbered` — нумерованный список 01–06

`<ol>` без маркеров; пункт — карточка (белый фон, бордер `--color-border`):
крупная контурная цифра + заголовок + описание. Цифра: `-webkit-text-stroke`
1.5px `--color-primary-soft` с прозрачной заливкой (через `@supports`;
без поддержки stroke — сплошная заливка `--color-primary-soft`); при hover
заливается `--color-accent`. Иконки не нужны — номер их заменяет.
Сетка 1 → 2 колонки (≥768) → 3 (≥1024).

### `b-tabs` — radio-табы без JS

Переключение панелей чистым CSS: скрытые radio + стилизованные `label`-чипы
(`input:checked + label` — фиолетовая заливка), панели — общие siblings
**после** input'ов, показ по `#id:checked ~ .panel--x{display:block}`.
Доступность: нативная семантика radio/label, `role="radiogroup"` +
`aria-label` на контейнере, `:focus-visible`-обводка на активном чипе,
touch-target чипов ≥ 44px. В чипах — короткие названия ролей, полные
заголовки и тексты — внутри панелей (контент не теряется).

### `b-svc-picker` — селектор услуг (карточка + панель)

Развитие канона `b-tabs` для страницы «Услуги»: слева карточки-`label`
(иконка Material Symbols, название, краткое описание), справа одна
панель с подробным описанием, фото `.b-media` и CTA. Разметка — как в
`b-tabs`: скрытые radio + карточки, панели — siblings в конце контейнера,
показ по `#id:checked ~ .panel--x{display:block}`; дефолт — первая услуга
(`checked` в разметке). Карточки компактные (иконка 36px, название
`--fs-small`, описание .8125rem) и склеены в единый список: `gap:0`, общие
линии (`margin-top:-1px`), крайние скруглены. Раскладка: 1 колонка
(моб. — чипы без иконки/описания) → 2 колонки карточек (≥768, панель во всю
ширину, `margin-top:12px`) → `grid-template-columns:minmax(0,420px)
minmax(0,1fr)` (≥1024): карточки `grid-column:1` (9 в один столбец, снова

### `.grid--bento` — bento-сетка решений

Вместо uniform-плиток: 1 колонка (моб) → 2 (≥768) → 4 (≥1024), gap 16/24.
Модификаторы ячеек (`.bento`): `--feature` — span 2×2, градиентная подложка
`--color-primary-light` → белый, увеличенные иконка/заголовок;
`--wide` — span 2 колонки; `--accent` — span 2 колонки, подложка

- Базовое состояние — **видимое**: анимация включается только при JS
  (`document.documentElement.classList.add('js')` в конце `<body>`);
  `html.js .reveal{opacity:0;translateY(12px);transition .4s}` →
  `.is-visible` через IntersectionObserver (threshold .15, rootMargin −40px).
  Без JS страница читаема полностью.
- Счётчики метрик: `<strong data-count="200000" data-suffix="+ м²">`
  со статичным значением внутри; JS анимирует от 0 при появлении
  (ease-out cubic, ~1.2s, `toLocaleString('ru-RU')`); без JS/при
  `prefers-reduced-motion` — статичные значения из HTML.
- `prefers-reduced-motion: reduce` — отключаются reveal, marquee и счётчики.

### Чередование фонов секций (ритм страницы)

Белый → полоса-marquee (`--color-primary-light`) → белый →
`--color-surface` → белый → `--color-surface` → белый →
`--color-primary-light` (`.section--tint-light`) → `--color-surface`
(контакты) → тёмный подвал. Большие цветные заливки по-прежнему запрещены —
только светлые подложки токенами.

### Hero Главной на всю высоту (≥768)

`--header-h:65px` (min-height `.site-header__inner` 64px + 1px нижняя граница),
`--marquee-h:48px` (min-height `.b-marquee`; полоса идёт сразу за hero).
<768 — базовое правило `min-height` не задаётся: hero по контенту.
≥768 — `.b-hero{display:flex;align-items:center;min-height:calc(100vh - var(--header-h) - var(--marquee-h))}`,
в `@supports (min-height:100svh)` — `svh`-вариант (гасит прыжок адресной
строки), `.b-hero__inner{flex:1 1 auto}` — композиция центрируется по
вертикали; из высоты вычтен размер бегущей строки, поэтому `шапка + hero +
полоса метрик` укладываются ровно в первый экран. С ≥768 — двухколоночная
композиция `1.15fr .85fr` (перенесена с 1024 ради укладки в экран),
метрики 2×2; ≥1024 — `gap:48px`, метрики 4×1, медиа 3/2.

### «Стандарты строительства» — карточки 2×2 на высоту фото

`.b-split{align-items:stretch}`; ≥1024 — `grid-template-columns:1fr 1fr`.
`.b-split__media{height:100%}`; `img{width:100%;height:100%;object-fit:cover;
aspect-ratio:4/3}` (на мобиле высота auto → работает aspect-ratio).
`.b-split__list{display:grid;grid-auto-rows:1fr;height:100%}`; ≥768 —
`grid-template-columns:repeat(2,1fr)`. `.b-split__item` — карточка (белый
фон, бордер `--color-border`, радиус, padding 20px, `height:100%`,
flex-column, gap 12px): иконка `.b-advantages__icon` — **над текстом**
(выше заголовка). Итог: группа 2×2 справа равна по высоте фото слева
(≥1024); ниже 768 карточки — 1 колонка.
